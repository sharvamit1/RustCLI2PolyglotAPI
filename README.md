# RustCLI2PolyglotAPI

Steps
1. Write code manually in **Rust** from scratch (only for improvements or advancements use AI)
2. Use AI to turn the Rust code into **Polyglot** language (pick one or max two to connect better)
3. Integrate web framework for API routing shown in repo for **Golang** (via Fiber, Gin), **Kotlin** (via Ktor)
4. In production environment, prefer **Quarkus** for Kotlin, to keep this repo simple leveraging **Ktor** for routing
5. In a same way, if you would like to work on **Python** along side Rust, you may integrate via FastAPI or Flask
6. If you would like to work on **TypeScript** along side Rust, integrate via Hono or Nestjs or Fastify or Koajs
7. If you would like to work on **Java** along side Rust, integrate via Spring WebFlux, Quarkus, or simply Javalin
8. Pick one **Frontend** to use **TypeScript** as core React.js, Vue.js, Svelte.js, Astro.js, or Nextjs, or Angular
9. Or consider using **Rust** for **Frontend** - Yew (Web), Dioxus (Cross Platform - Web, Desktop, Mobile*)
10. Integrate **Tauri** for **Desktop** support (In any web only version, either using Rust powered Yew or Nextjs)

Note: This is how one CLI that written in **Rust** manually with the use of **AI** may help to achieve **Big Visions** easily
